## Uruchomienie Frontendu (Aplikacja Mobilna)

Wymagania: Zainstalowane **Node.js** na komputerze oraz aplikacja **Expo Go** na telefonie.

1. **Wejdź do folderu z frontendem:**
```bash
   cd frontend
```
2. **Zainstaluj wymagane paczki**
```bash
   npm install
```
4. **W pliku ```api/client.ts``` należy zmienić adres ip na adres na którym postawiony jest serwer backend (najczęściej adres twojego komputera w sieci domowej).**
5. **Uruchom aplikacje:**
```bash
   npx expo start
```

W oknie konsoli powinien pojawić się teraz kod QR który należy zeskanować telefonem.
